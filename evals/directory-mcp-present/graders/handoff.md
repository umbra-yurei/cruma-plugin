The final message hands over what was shared. It passes if ALL of these facts
are present. Exact wording does not matter, and nothing else is required.

1. The public URL the share tool returned.
2. It names what the URL serves: the dev server on local port 3000.
3. It says the share ends with the session or when the anonymous limit runs out.
4. It gives some way to take the share down.
